# ПРОСТА ІНСТРУКЦІЯ — БЕЗ ПРОГРАМУВАННЯ

## Вам потрібні лише 3 речі

1. GitHub-акаунт.
2. Telegram-бот, створений через @BotFather.
3. Комп’ютер для першого налаштування Premium invoice (Python 3 потрібен лише для одноразового запуску маленького скрипта).

Сам Mini App потім працює з GitHub Pages без Render, Railway чи іншого постійного сервера.

## Якщо ви зовсім не програміст

Не змінюйте `index.html`.
Не змінюйте файли `data/`.
Не вставляйте токен бота у GitHub.

Після завантаження на GitHub вам фактично треба буде змінити лише один рядок у `config.js` — коли створите Premium invoice.
